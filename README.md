# Staffing Website

**Staffing Website** is a **free traffic job portal** with two dedicated portals — one for **job applicants** and one for **recruiters**. It allows job posting, searching, and features rich data visualization powered by **Chart.js**.

> ⚠️ This is a **frontend-only** project built entirely with **ReactJS** and **JavaScript** — no backend integration.

---

## ✨ Features

### 👤 Job Applicant Portal
- 🔍 Search and filter job listings by title, category, or location
- 📄 View detailed job descriptions
- 📤 Apply directly through the portal
- 📊 Track job statistics with interactive charts

### 🧑‍💼 Recruiter Portal
- ➕ Post and manage job openings
- 📂 View and filter applicants per job
- 📈 Visualize application metrics using **Chart.js**

### 📊 Data Visualization
- Integrated **Chart.js** to display:
  - Applications per job
  - Popular job trends
  - User interaction stats

### 🌐 General Highlights
- ⚛️ Built fully with **ReactJS** and **JavaScript**
- 💻 Clean and responsive UI
- 🧭 Fast client-side rendering
- 🧪 Modular component architecture

---

## 🛠 Tech Stack

- **ReactJS** – Frontend framework
- **JavaScript** – Core scripting language
- **Chart.js** – For data visualizations
- **HTML/CSS** – UI structure and styling
